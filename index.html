01 เหตุผล

เซลเพจที่ดี
ไม่ควรเริ่มจากศูนย์

เราเห็นร้านเล็ก ๆ จำนวนมากเสียยอดขาย เพราะหน้าเว็บที่ต้องใช้เวลาหลายวัน และเครื่องมือที่ไม่ได้ออกแบบมาสำหรับมือถือ

A — 01

ลิงก์เดียวที่ขายได้

แทนที่จะกระจายลิงก์ในไบโอ TikTok ให้ทุกอย่างจบในหน้าเดียว ตั้งแต่จุดสนใจจนถึงปุ่มสั่งซื้อ

B — 02

เร็วเท่าที่มือถือต้องการ

หน้าเว็บเป็น static HTML ที่โหลดเสร็จในเสี้ยววินาที ไม่มีแบ็กเอนด์ให้รอ ไม่มีปลั๊กอินให้พัง

C — 03

ข้อมูลเป็นของคุณจริง ๆ

ทุกหน้าเก็บเป็นไฟล์ JSON ใน GitHub ของคุณ เปิดอ่าน แก้ไข หรือย้ายเจ้าบ้านได้ทุกเมื่อ

02 ฟีเจอร์

เครื่องมือเท่าที่ต้องใช้
ไม่มากไปกว่านั้น

ทุกฟีเจอร์ถูกเลือกมาเพื่อคนที่ต้องการเปิดร้านวันนี้ ไม่ใช่เรียนรู้ระบบเป็นเดือน

ลองใช้ในแอป
01

บล็อกประกอบหน้า

10 บล็อกที่ใช้จริง — ฮีโร่, สินค้า, จุดเด่น, รีวิว, นับถอยหลัง, FAQ, ลิงก์ และปุ่มสั่งซื้อ ลากสลับได้ในคลิกเดียว

02

พรีวิวสดขณะพิมพ์

เห็นหน้าจอจริงในกรอบมือถือทุกครั้งที่แก้ข้อความ สี หรือราคา ไม่ต้องกดบันทึกแล้ว refresh

03

บันทึกลง GitHub

เชื่อม repo ครั้งเดียว ทุกการกดบันทึกคือ commit จริง พร้อมประวัติย้อนหลังและเจ้าของที่ชัดเจน

03 ขั้นตอน

เลือกเทมเพลต

05 คำถาม

เรื่องที่คนถามบ่อย

ถ้ายังไม่เจอคำตอบ ทักมาคุยกับเราได้ผ่านช่องทางในหน้าเอกสาร

ต้องเขียนโค้ดเป็นไหม

ไม่ต้องครับ ทุกอย่างทำผ่านหน้าแก้ไขแบบฟอร์มและพรีวิวสด ถ้าอยากปรับลึกกว่านั้นก็แก้ไฟล์ JSON หรือ CSS ได้โดยตรง เพราะโค้ดทั้งหมดอยู่ใน repo ของคุณ

ข้อมูลถูกเก็บไว้ที่ไหน

สองที่ — สำเนาทำงานอยู่ในเบราว์เซอร์ของคุณ และไฟล์จริงอยู่ใน repository GitHub ที่คุณเชื่อมไว้ เราไม่มีเซิร์ฟเวอร์กลางที่เก็บข้อมูลร้านค้า

ต้องใช้ GitHub token แบบไหน

แนะนำ fine-grained personal access token ที่จำกัดเฉพาะ repo เดียว และให้สิทธิ์ Contents: Read and write เท่านั้น ใส่ในหน้าตั้งค่าแล้วเก็บไว้ในเครื่องของคุณ ไม่ถูกส่งไปที่อื่น

ใช้โดเมนของตัวเองได้ไหม

ได้ครับ หลังจาก deploy บน Vercel แล้ว สามารถเพิ่มโดเมนในหน้า Project Settings → Domains ของ Vercel ได้ทันที

ถ้ายังไม่เชื่อม GitHub ใช้ได้ไหม

ได้ครับ ใช้โหมด local เพื่อร่างและพรีวิวได้เต็มรูปแบบ ข้อมูลจะอยู่ในเบราว์เซอร์จนกว่าคุณจะเชื่อม repo แล้วกดซิงก์
